怎么订阅？
  • iOS：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历 → 粘贴上面的网址。
  • Android / Google 日历：其他日历 → 通过网址订阅 → 粘贴上面的网址。
  • Outlook / Apple 日历（电脑）：添加日历 → 从网络订阅 → 粘贴上面的网址。
  • 只想看一眼：点「↓ 下载」，双击导入即可（但不会自动更新）。

必须用上面那个完整网址订阅，直接给日历 App 一个本地文件是不行的—— 它需要能定期访问这个地址来取最新内容。

这个站是什么

把散落在「教育部竞赛目录」「学校 A/B 类认定名单」「实践教学中心通知」里的信息， 汇成一张按电气工程及其自动化相关度排序的总表。数据来自官方源，可重跑脚本重新生成。

必须知道的数据缺陷

    数据来源

      字段说明

      电气相关度
      1–5 分。5 = 电气/自动化核心赛事，1 = 基本无关（其他学科专属）。为 AI 初判，需人工复核。
      西交认定
      A 类 / B 类，来自西交名单。该名单为旧版且不完整，因此多数条目显示「未认定（待核）」——这不代表学校未认定。
      教育部目录
      是否在《2025 年教育部认可的全国大学生学科竞赛目录清单》（84 项）内。
      归口部门
      学校负责该赛事的部门：教务处 / 团委 / 工程坊 / 研究生院 / 医学部。

      怎么更新

      python scripts\crawl_xjtu_notices.py    # 抓最新校内通知
python scripts\parse_moe_catalog.py     # 解析教育部目录 PDF
